# Bug Report

## Bug ID

BUG-001

## Title

Deposit Button Is Missing From the Success Modal After Registration via Social Network

## Environment

* Platform: Desktop Web
* Browser: chrome
* OS: 26.6.2
* Website: Melbet
* Build/Version:151.0.7922.174 (Official Build) (arm64)

## Preconditions

* User is not registered or logged in.
* User has access to social network accounts .

## Steps to Reproduce

1. Open the Melbet website on a desktop browser.
2. Click "register".
3. Select a social network registration option.
4. Complete the registration process using the selected social network account.
5. Observe the success modal displayed after successful registration.

## Actual Result

The registration success modal is displayed, but the "Deposit" button is missing.

## Expected Result

The registration success modal is displayed, but the "Deposit" button is missing.
