# Bug Report

## Bug ID
BUG-001

## Title
Deposit Button Is Missing From the Success Modal After Registration via Social Network

## Environment
- Platform:Desktop
- Browser:chrome
- OS:26.6.2
- Website:melbet
- Build/Version:151.0.7922.174 (Official Build) (arm64)

## Preconditions
- User is not registered/logged in.
- User has access to a social network account.

## Steps to Reproduce
1. Open the Melbet website on desktop.
2. Click "Registration".
3. Select a social network registration option.
4. Complete the registration process using the social network account.
5. Observe the success modal displayed after successful registration.

## Actual Result
The registration success modal is displayed, but the "Deposit" button is missing.

## Expected Result
The registration success modal should contain a "Deposit" button, allowing the newly registered user to proceed directly to the deposit page.

## Severity
Medium

## Priority
High
