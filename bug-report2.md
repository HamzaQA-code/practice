# Bug Report
# Bug ID

BUG-002

# Title

All Languages Are Displayed in the Language Selector on Mobile Instead of Only EN, FR, and AR

# Environment
- Platform: Mobile
- Browser: Chrome
- OS: 15
- Website: melbet
- Build/Version: 151.0.7922.174

# Preconditions
- User opens the Melbet website on a mobile device.
- The website is fully loaded.

# Steps to Reproduce
1. Open the Melbet website on mobile.
2. Open the language selector.
3. Observe the list of available languages.

# Actual Result
The system displays all available languages in the language selector on mobile.

# Expected Result

The mobile language selector should display only the supported languages: EN , FR , AR

# Severity

Medium

# Priority

Medium
