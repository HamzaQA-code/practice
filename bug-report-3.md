# Bug Report
Bug ID

# BUG-003

Title

Incorrect Number of Free Spins Is Displayed on the Registration Form

# Environment
- Platform: desktop
- Browser: Chrome
- OS: 26.6.2
- Website: melbet
- Build/Version: 151.0.7922.174 

 # Preconditions
- User is not registered/logged in.
- The registration form is available.

  # Steps to Reproduce
1. Open the Melbet website.
2.  Click "Registration".
3. Open the registration form.
4.  Check the Free Spins information displayed on the form and the banner.

  # Actual Result

The registration form displays 150 Free Spins.

# Expected Result

The registration form should display 180 Free Spins.

# Severity

Medium

# Priority

High
